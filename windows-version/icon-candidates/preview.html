KOReader Windows 图标候选

这里先只展示可替换方向，不改程序。当前建议优先选 Lucide 线性 SVG：风格干净，24px 下清晰，后续可转成 PNG 给 Tkinter 使用。

推荐组合已用绿色标出。你确认后，我再把选中的 SVG 转为运行时资源，并替换按钮文字/emoji。
浅色标题栏推荐效果
深色标题栏推荐效果

昼夜切换

标题栏右侧
Moon 推荐夜间入口

moon.svg，语义最直接，小尺寸识别稳定。

Sun 推荐日间入口

sun.svg，和 Moon 成对使用最清楚。

Moon Star

moon-star.svg，更有装饰感，但 20px 时细节略多。

Sun Moon

sun-moon.svg，适合“自动/切换”语义，单按钮也可以。

置顶窗口

标题栏右侧
Pin 推荐

pin.svg，和当前图钉语义一致，替换成本最低。

Pin Off

pin-off.svg，可用于“已取消置顶”状态。

Bookmark

bookmark.svg，更像收藏，不如 Pin 准确。

Bookmark Check

bookmark-check.svg，状态感强，但窗口置顶语义偏弱。

旋转屏幕

默认 F6
Rotate CW 推荐

rotate-cw.svg，旋转动作明确，和当前“顺时针切换”最接近。

Rotate CCW

rotate-ccw.svg，如果设备实际逆时针旋转可选。

Rotate Square

rotate-cw-square.svg，更像“屏幕/窗口旋转”，但图形更密。

全刷

默认 F5
Refresh CW 推荐

refresh-cw.svg，刷新语义最通用，替代当前闪电更准确。

Refresh CCW

refresh-ccw.svg，和推荐款同义，只是方向不同。

Repeat

repeat.svg，更像循环/重做，不够像屏幕全刷。

Repeat 2

repeat-2.svg，视觉更紧凑，但语义也偏循环。

截图

默认 F7
Camera 推荐

camera.svg，用户认知最强，和当前相机 emoji 一致。

Image

image.svg，更像打开图片/图库，不是直接截图。

Scan Line

scan-line.svg，有“捕获屏幕”的感觉，但语义稍抽象。

Scan

scan.svg，适合截图区域/扫描类功能。

设备休眠

默认 Esc
Power 推荐

power.svg，设备控制语义强，适合替代睡觉 emoji。

Circle Power

circle-power.svg，按钮感更强，但图形较满。

Power Off

power-off.svg，容易理解成关机，风险略高。

Moon

moon.svg，像休眠，但会和昼夜按钮撞语义。

断开连接

连接页
Unplug 推荐

unplug.svg，最像断开设备连接。

Log Out

log-out.svg，更像退出账号，不如 Unplug 精准。

X

x.svg，适合关闭按钮，但断开语义较弱。

Circle X

circle-x.svg，删除/错误感偏强。

上一页 / 下一页

方向键
Chevron Left 推荐

chevron-left.svg，适合翻页按钮，视觉轻。

Chevron Right 推荐

chevron-right.svg，和左箭头成对。

Arrow Left

arrow-left.svg，更像返回/移动，重量略大。

Arrow Right

arrow-right.svg，适合强调方向，但不如 Chevron 轻。
